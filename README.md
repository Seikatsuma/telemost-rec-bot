# Запись встреч Яндекс Телемоста — Telegram-бот

Бот создаёт встречу в Яндекс Телемосте (или берёт вашу ссылку), заходит в неё участником «Запись встречи»
и записывает разговор. Когда все выйдут — присылает в Telegram аудио и файл расшифровки с коротким конспектом.

- **Новая встреча** — ссылка приходит сразу, бот в звонке через ~6 секунд
- **Своя ссылка** — пришлите боту ссылку `telemost.yandex.ru/j/…`, он подключится гостем (аккаунт не нужен)
- **Виден участникам** как «Запись встречи»: вместо камеры — картинка «идёт запись», микрофон выключен
- **Подписывает говорящих именами** — Телемост сам знает, у кого горит микрофон: бот ведёт журнал «кто и когда говорил» по аккаунтам участников (не по голосу) и подставляет настоящие имена в расшифровку
- **Случайно вышли** — запись не рвётся: бот ждёт 30 секунд и продолжает в тот же файл
- **Все вышли** — запись закрывается, бот выходит, в чат приходят аудио и расшифровка
- **Никто не пришёл** за 15 минут — бот отключается сам
- **Остановить** — кнопкой в любой момент

Расшифровка — Deepgram nova-3 файлом целиком (бесплатные $200 кредита новому аккаунту ≈ 700 часов);
при сбое — Groq (Whisper, бесплатный ключ). Конспект — DeepSeek или Groq.

> Встречу записывают участники разговора — предупредите всех. Бот виден в списке участников под именем «Запись встречи».

## Что нужно

- Сервер или компьютер с Linux (Ubuntu 22.04/24.04), 2 ядра, от 2 ГБ свободной памяти, доступ в интернет
- Python 3.10+, ffmpeg (`sudo apt install python3-venv ffmpeg`)
- Токен бота — [@BotFather](https://t.me/BotFather) → `/newbot` (бесплатно)
- Ключ Deepgram — [console.deepgram.com](https://console.deepgram.com) (бесплатно, $200 стартового кредита). Без него бот расшифровывает через Groq — тогда нужен ключ Groq: [console.groq.com/keys](https://console.groq.com/keys) (бесплатно)
- Аккаунт Яндекса — только чтобы бот создавал встречи по кнопке (вход по QR-коду, пароль бот не хранит). Без него бот всё равно пишет любую встречу по ссылке — заходит гостем

## Установка

**Ставит нейросеть?** Отдайте своему ИИ-агенту файл [AGENTS.md](AGENTS.md) — там пошаговая
инструкция: где взять бесплатные ключи, какая нужна машина, как проверить, что всё встало.

```bash
git clone https://github.com/Seikatsuma/telemost-rec-bot
cd telemost-rec-bot
./install.sh
```

Скрипт создаст окружение, скачает Chromium, создаст `.env` и проверит запись звука на локальном стенде.
Если он попросит — один раз выполните `sudo venv/bin/playwright install-deps chromium` и запустите `./install.sh` снова.

Впишите в `.env` как минимум:

```
BOT_TOKEN=123456:ABC...
DEEPGRAM_API_KEY=ваш_ключ
```

## Первый запуск

```bash
venv/bin/python bot.py
```

В Telegram:

1. `/start` — бот закрепится за вами (станет вашим) и покажет кнопки
2. `/login` — придёт QR-код; откройте приложение Яндекс → «Умная камера», наведите на код, подтвердите вход
3. «🎙 Новая встреча» — ссылка придёт сразу, бот подключится
4. Зайдите по ссылке, поговорите, выйдите — через 3 минуты придут аудио и расшифровка

Проверка без людей: `/selftest` — бот сам создаст встречу, зайдёт с тестовым участником и пришлёт запись.

## Кнопки и команды

| | |
|---|---|
| 🎙 Новая встреча | создать встречу, прислать ссылку, подключить бота |
| ⏹ Остановить | закончить запись сейчас (если встреч несколько — выбор) |
| 📋 Статус | что сейчас пишется |
| ссылка на встречу | подключить бота к вашей встрече |
| `/login` | вход в Яндекс по QR (только владелец) |
| `/text` | расшифровка вкл/выкл для этого чата |
| `/selftest` | проверка на тестовой встрече (только владелец) |

## Дать попробовать другим

- **Конкретным людям**: пусть напишут боту — он ответит их Telegram id. Впишите id через запятую в `OWNER_IDS` и перезапустите бота.
- **Всем**: `ALLOW_ALL=1`. Каждый видит и останавливает только свои встречи; встречи создаются с вашего аккаунта Яндекса.

## Запуск службой (перезапуск сам)

```bash
mkdir -p ~/.config/systemd/user
cp deploy/telemost-rec-bot.service ~/.config/systemd/user/
# если бот лежит не в ~/telemost-rec-bot — поправьте пути в файле службы
systemctl --user daemon-reload
systemctl --user enable --now telemost-rec-bot
loginctl enable-linger "$USER"      # чтобы служба жила без входа в систему
journalctl --user -u telemost-rec-bot -f
```

## Настройки (`.env`)

Все настройки с пояснениями — в `.env.example`. Главные:

| | по умолчанию | |
|---|---|---|
| `DEEPGRAM_API_KEY` | — | расшифровка через Deepgram; пусто — через Groq |
| `DEEPSEEK_API_KEY` | — | конспект через DeepSeek вместо Groq |
| `GRACE_SEC` | 30 | сколько ждать вернувшихся, прежде чем закончить запись |
| `IDLE_LEAVE_SEC` | 3600 | сколько бот сторожит ссылку после создания встречи |
| `MAX_MEETINGS` | 3 | встреч одновременно (браузер на встречу ~0.5–1 ГБ) |
| `WARM_ENABLED` | 1 | заготовка встречи: мгновенная ссылка ценой ещё одного браузера |
| `BOT_CAMERA` | 1 | картинка вместо камеры (`assets/camera.png`) |
| `PUBLIC_REPO_URL` | — | ссылка, которую бот предложит чужому человеку («поднимите своего») |

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| «Нужен вход в Яндекс» | `/login` и отсканировать QR (вход иногда слетает через несколько недель) |
| Бот не заходит во встречу | `/selftest` — пришлёт снимок экрана бота; логи в `logs/bot.log` |
| «Бот в зале ожидания» | организатор встречи должен впустить «Запись встречи» |
| Расшифровка не пришла | бесплатный Groq ограничивает объём звука в час — аудио придёт всё равно |
| Chromium не запускается | `sudo venv/bin/playwright install-deps chromium` |

## Как это устроено

- `bot.py` — Telegram: кнопки, доступ, отправка аудио и расшифровки
- `warm.py` — заготовка: заранее созданная встреча и браузер на экране подключения
- `meeting.py` — один браузер на встречу: вход, наблюдение за участниками, пауза, перезаход при обрыве
- `inject.js` — внутри страницы: считает участников по сообщениям Телемоста, пишет звук входящих дорожек
- `telemost.py` — вход в Яндекс по QR, создание встречи, подключение гостем
- `postprocess.py` — склейка звука, расшифровка Groq, конспект
- `tests/` — стенды без Телемоста (`harness_capture.py`, `e2e_fake_telemost.py`) и живые проверки

У бесплатного Телемоста нет API, поэтому бот работает через браузер (Playwright + Chromium) — как обычный участник.
